# 褒めてくれるタスク管理アプリ

スマホでも使える、秘書キャラクターが褒めてくれるタスク管理アプリです。
`index.html` だけで動作し、タスクは端末の localStorage に保存されます。

## ファイル構成

```
praise-task-app/
├── index.html   ← アプリ本体（これだけで起動可能）
├── normal.png   ← 通常時のキャラクター画像
├── happy.png    ← タスク進行中・全部完了時のキャラクター画像
├── tired.png    ← 「今日はこれで終了」押下後のキャラクター画像
└── README.md
```

`normal.png` / `happy.png` / `tired.png` は `index.html` と同じフォルダに置いてください。

## GitHub Pagesでの公開手順

1. GitHubで新しいリポジトリを作成する（例: `praise-task-app`）。
2. `index.html`、`normal.png`、`happy.png`、`tired.png` をリポジトリの**ルート直下**にアップロードする。
   - フォルダ構成を変える場合は、`index.html` 内の `src="normal.png"` などのパスも合わせて修正してください。
3. リポジトリの **Settings → Pages** を開く。
4. 「Build and deployment」の **Source** を `Deploy from a branch` に設定する。
5. **Branch** を `main`（または公開したいブランチ）、フォルダを `/ (root)` にして **Save** をクリックする。
6. 数分待つと、ページ上部に公開URLが表示される。
   - 例: `https://ユーザー名.github.io/praise-task-app/`
7. そのURLにアクセスしてアプリが表示されることを確認する。

## iPhone（Safari）でホーム画面に追加する手順

1. iPhoneのSafariで上記の公開URLを開く。
2. 画面下部の「共有」アイコン（□に↑のマーク）をタップする。
3. メニューから「ホーム画面に追加」を選択する。
4. 名前を確認して「追加」をタップする。
5. ホーム画面にアプリのアイコンが追加され、タップするとフルスクリーンに近い状態で起動する。

## データの保存について

- タスクの内容・完了状態・「今日はこれで終了」フラグ・最終終了日は、すべて**ブラウザのlocalStorage**に保存されます。
- そのため、データは**この端末・このブラウザ内のみ**で保持されます（他の端末やブラウザとは同期されません）。
- ブラウザのキャッシュ／サイトデータを削除すると、保存していたタスクは消去されます。

## 機能概要

- タスクの追加・完了チェック・削除
- 進捗バーによる達成率の表示
- 達成状況に応じてキャラクター画像・セリフが変化
  - タスク0件 → `normal.png`
  - タスク達成率1〜99% / 100% → `happy.png`
  - 「今日はこれで終了」押下後 → `tired.png`
- 「今日はこれで終了」ボタンで、その日の未完了タスクを翌日に自動で繰り越し
- 翌日アプリを開くと、終了状態が自動でリセットされる
